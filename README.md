# FT课程开发 Skill

> 基于曹勇安「四真三化(FT)」课程开发方法论，将教学大纲转换为结构化开课说明的 AI 辅助技能。

## 方法论出处

本 skill 严格遵循曹勇安著《"四真三化"课程开发原理与方法》中的课程开发规则。四真三化(FT) = 真实环境、真学、真做、掌握真本领 + 工作任务课程化、教学任务工作化、工作过程系统化。

## 文件说明

| 文件 | 用途 |

| `空白模板_开课说明.md` | 开课说明空白模板（固定标题 + 通用文本） |

## 启动：双模式选择

收到教学大纲后，提供两种模式：

| 模式 | 说明 |
|------|------|
| 🅰 **自主生成** | 全自动执行全部规则，一次性输出完整开课说明 docx，不打断不询问 |
| 🅱 **人机协作** | 分 7 步逐项对话，每步用户确认后推进，适合需要精细调整的场景 |

## 工作流（7步交互）

```
输入：教学大纲
  │
  ├─ 第1步 解析基础信息 ───→ 用户确认
  ├─ 第2步 教学目标+毕业要求映射 ───→ 用户调整
  ├─ 第3步 二级矩阵+课点 ───→ 用户调整
  ├─ 第4步 按项目：项目教学目标→课点KSA ───→ 逐项目确认
  ├─ 第5步 三级矩阵 ───→ 按项目输出，用户调整
  ├─ 第6步 开课说明正文一次性确认 ───→ 一次性输出全部非矩阵内容
  └─ 第7步 组装开课说明 ───→ 输出 docx
```

## 输出结构

生成的 docx 开课说明包含：
基础信息 → 课程简介（定位+整体介绍+目标+项目设计+思政融入+实施）→ 课程要求（7条含固定文本）→ 考核评价（双表）→ 附件（一级/二级/三级矩阵）→ 签字

## 关键规则摘要

- 毕业要求指标点 → 教学目标：1 对 1-2（不反向）
- 通识教育必修课：固定使用毕业要求 5 + 10
- 二级矩阵：项目(左列) × 教学目标(上表头，写完整内容)，同一项目课点分散在不同目标下
- 1 学时 = 1 课点；1 课点 → 1 教学目标（硬约束）
- 三级矩阵：课点 | 教学目标1:[全文] | 教学目标2:[全文] | 学法 | 教法 | 学习产出及测量标准 | 周数 | 学时
- 每项目默认 2 个教学目标
- KSA 三维一体：K 每课点 2 个，S 每课点 1 个，A 全局 ≤5 个
- ★/☆ 基于实际支撑逐条独立判断
- 学习产出 ≥3 条定量测量标准，独立可读
- 第 6 步一次性输出非矩阵内容，统一确认
- 思政融入覆盖全部课点
- 课程要求含 7 条模板固定文本
- 附件无课程进度表，直接矩阵
