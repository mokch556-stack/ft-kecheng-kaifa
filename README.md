# FT课程开发 Skill

> 基于曹勇安「四真三化(FT)」课程开发方法论，将教学大纲转换为结构化开课说明的 AI 辅助技能。

## 方法论出处

本 skill 严格遵循曹勇安著《"四真三化"课程开发原理与方法》中的课程开发规则。四真三化(FT) = 真实环境、真学、真做、掌握真本领 + 工作任务课程化、教学任务工作化、工作过程系统化。

## 依赖

| 库 | 用途 |
|---|---|
| `python-docx` | 单文档排版与生成 |
| `docxtpl` | 基于 docx 模板批量填充（可选） |
| `mammoth` | docx 模板转 markdown 预览 |

## 工作流（7步交互）

```
输入：教学大纲
  │
  ├─ 第1步 解析基础信息 ───→ 用户确认
  ├─ 第2步 教学目标+毕业要求映射 ───→ 用户调整
  ├─ 第3步 二级矩阵+课点 ───→ 用户调整
  ├─ 第4步 按项目：项目教学目标→课点KSA ───→ 逐项目确认
  ├─ 第5步 三级矩阵 ───→ 按项目输出，用户调整
  ├─ 第6步 开课说明正文确认 ───→ 用户逐项确认（定位/思政/实施/纪律/考核/参考资料）
  └─ 第7步 组装开课说明 ───→ 输出 docx
```

## 关键规则摘要

- 毕业要求指标点 → 教学目标：1 对 1-2（不反向）
- 通识教育必修课：固定使用毕业要求 5（使用现代工具）+ 10（沟通）
- 二级矩阵：项目(左列) × 教学目标(上表头)，课点落入交叉格
- 1 学时 = 1 课点；1 课点 → 1 目标（硬约束）
- KSA 三维一体：K 每课点 2 个，S 每课点 1 个，A 全局 ≤5 个
- ★/☆ 标注在 K/S/A 之前，逐条独立判断实际支撑程度
- 学习产出 ≥3 条定量测量标准，独立可读
- 三级矩阵按项目输出，一个项目一张表
- 组装 docx 前须与用户逐项确认非矩阵内容

## 输出结构

生成的 docx 开课说明包含：基础信息 → 课程简介 → 课程设计（项目创设 + 思政融入）→ 课程实施 → 课程要求 → 考核评价 → 课程计划 → 附件（一级/二级/三级矩阵）→ 参考资料 → 签字

## 使用说明

将此 SKILL.md 导入支持 skill 机制的工具，提供教学大纲后按 7 步交互推进即可。每步需用户确认后再进入下一步。
