# FT课程开发 Skill

> 基于曹勇安「四真三化(FT)」课程开发方法论，将教学大纲转换为结构化开课说明的 AI 辅助技能。
> **v9.0 起三合一**：一键生成 / 人机协作 7 步 / 调优已有开课说明（一次性）。

## 方法论出处

本 skill 严格遵循曹勇安著《"四真三化"课程开发原理与方法》中的课程开发规则。四真三化(FT) = 真实环境、真学、真做、掌握真本领 + 工作任务课程化、教学任务工作化、工作过程系统化。

v9.0 融合 10 阶段调优方法论（沉淀自《人工智能通识》《管理信息系统》多轮实战），调优规则直接并入生成规则——**生成即达标**，不需要"先生成、再调优"两道工序。

## 启动：三模式选择

收到任务后，先确认模式（🅲 调优时还要过必问确认清单；🅰/🅱 生成时问周次）：

| 模式 | 说明 |
|------|------|
| 🅰 **一键生成开课说明** | 全自动执行全部规则 + 质量标准自检，一次性输出完整 docx，不打断不询问 |
| 🅱 **人机协作 7 步** | 分 7 步逐项对话，每步用户确认后推进，适合需要精细调整的场景 |
| 🅲 **调优已有开课说明** | 一次性诊断 + 修改 + 输出新版 docx 和调优报告，不打断不走分步 |

## 工作流（模式 B 7步交互）

```
输入：教学大纲 + 周次确认
  │
  ├─ 第1步 解析基础信息 ───→ 用户确认
  ├─ 第2步 教学目标+毕业要求映射 ───→ 用户调整（严格引用大纲原文）
  ├─ 第3步 二级矩阵+课点 ───→ 用户调整（确认项目关系）
  ├─ 第4步 按项目：项目教学目标→课点KSA ───→ 逐项目确认（KSA全局唯一编号）
  ├─ 第5步 三级矩阵 ───→ 按项目输出，用户调整（末行加总结行+汇总行）
  ├─ 第6步 开课说明正文一次性确认 ───→ 一次性输出全部非矩阵内容
  └─ 第7步 组装开课说明 ───→ 输出 docx
```

## 调优流程（模式 C 10阶段，一次性）

```
输入：已有开课说明 docx + 必问确认清单（Q1学期变量/Q2特色教学法/Q3基本面）
  │
  ├─ Phase 0 读取与解析（跑 analyze_syllabus.py 诊断）
  ├─ Phase 1 结构体检（10项标准章节）
  ├─ Phase 2 目标体系审查（布鲁姆分层）
  ├─ Phase 3 三层次矩阵对齐
  ├─ Phase 4 课点级质量审查（K/S/A + 可测量产出 + 教法学法独立）
  ├─ Phase 5 三级矩阵结构工程（拆vMerge / 达成测量行 / 学时重标 / 去渠道）
  ├─ Phase 6 思政融入审查
  ├─ Phase 7 考核评价审查
  ├─ Phase 8 一致性与措辞打磨
  └─ Phase 9 交付（新版 docx + 调优报告）
```

## 输出结构

生成的 docx 开课说明包含：
基础信息（13项）→ 课程简介（定位+整体介绍+目标+项目设计+思政融入+实施）→ 课程要求（7条含固定文本）→ 考核评价（双表）→ 附件（一级/二级/三级矩阵）→ 签字

## 关键规则摘要

- 毕业要求指标点 → 教学目标：1 对 1-2（不反向）
- 通识教育必修课：固定使用毕业要求 5 + 10
- 教学目标：严格引用大纲原文，只字不差，无 `[]`
- 二级矩阵：项目(左列) × 教学目标(上表头，写完整内容)，同一项目课点分散在不同目标下
- 1 学时 = 1 课点；1 课点 → 1 教学目标（硬约束）
- 三级矩阵：课点 | 教学目标1:[全文] | 教学目标2:[全文] | 学法 | 教法 | 学习产出及测量标准 | 周数 | 学时
- 每项目默认 2 个教学目标
- KSA 三维一体：K 每课点 2 个，S 每课点 1 个，A 全局 ≤5 个；编号全局唯一连续
- ★/☆ 基于实际支撑逐条独立判断；★K 禁止配"了解"等低阶动词
- 学习产出 ≥3 条定量测量标准，独立可读、可测量（数量/实物/长度/行为/质量）
- 三级矩阵每项末行：学习产出及测量标准（以教学目标为单位考核）+ 学时汇总行
- 三级矩阵数据区禁止垂直合并（vMerge），每课点独立；列头合并保留
- 第 6 步一次性输出非矩阵内容，统一确认
- 思政融入覆盖全部课点
- 课程要求含 7 条模板固定文本
- 附件无课程进度表，直接矩阵
- **课程实施绑定句式**："工作坊式的教学组织形式，集体主义的团队学习方式，教学相长的212学习方法。"（不可拆分改动，212=2分钟小组展示+1分钟学生点评+2分钟教师点评）
